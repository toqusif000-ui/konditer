# Библиотека кондитера — статический сайт для GitHub Pages

Это ПОЛНАЯ самодостаточная сборка. Все файлы уже здесь, ничего скачивать/устанавливать не нужно.

## Как деплоить (для Claude Code)

Это обычный статический сайт. НЕ пересобирай, НЕ трогай код, НЕ меняй пути.

1. Закоммить содержимое этой папки в репозиторий как есть (в корень репо или в `/docs`).
2. Включи GitHub Pages: Settings → Pages → Source = ветка, папка = корень (или `/docs`).
3. Точка входа — `index.html`.

Всё. Сайт откроется по адресу Pages.

## Что внутри (всё обязательно)

- `index.html`      — страница (Design Canvas: `<x-dc>` + рантайм)
- `support.js`      — рантайм, который рендерит страницу (грузится как `./support.js`)
- `_ds/`            — дизайн-система BkDS: шрифты, стили, бандл компонентов
- `assets/`         — фотографии (коллаж, карточки разделов, обложки)
- `uploads/`        — фото автора на обложке книги

## Важно

- Все пути ОТНОСИТЕЛЬНЫЕ (`_ds/...`, `./support.js`, `assets/...`, `uploads/...`),
  поэтому работает и в корне домена, и в подкаталоге `user.github.io/repo/`.
- Часть картинок подставляется скриптом на лету — папку `assets/` удалять нельзя.
- Нужен интернет у зрителя (страница подгружает React/шрифты Google) — для GitHub Pages это норма.
- Проверено локально: все изображения грузятся, консоль чистая (кроме безвредного предупреждения из бандла дизайн-системы).
